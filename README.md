# TripSplit

Split trip expenses between member groups (for example "My side" and "Anna side").

## Get the APK

1. Push this repo to GitHub (branch `main`).
2. Open the **Actions** tab and wait for **Build APK** to finish (about 5 to 8 minutes).
3. Open the finished run, scroll to **Artifacts**, download **TripSplit-apk**, unzip it, and install `app-release.apk` on your phone.

You can also start a build manually: Actions, Build APK, Run workflow.
